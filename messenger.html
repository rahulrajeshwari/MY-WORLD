User ID कैसे बनाएं?

1. MY WORLD में Login करें और Email Verify करें।

2. अपनी अलग User ID चुनें, जैसे rahul_001 या kishan123। 4–24 छोटे अंग्रेजी अक्षर, अंक या underscore (_) इस्तेमाल करें।

3. Save User ID दबाएं। ID पहले से किसी की है तो दूसरी चुनें।

Message कैसे भेजें और देखें?

दोस्त की User ID डालें, Open Chat दबाएं, संदेश लिखें और Send करें। दोस्त भी आपकी User ID डालकर वही चैट खोल सकता है। चैट खुली होने पर नए संदेश दिखाई देंगे। Recent Chats इस डिवाइस पर सेव होते हैं। अलग online Inbox और push notifications अभी उपलब्ध नहीं हैं।

केवल verified email वाले accounts. Messages Firebase में सेव होते हैं; end-to-end encryption नहीं है। OTP या password साझा न करें। Customer ID lookup, delete, forward, photo अभी उपलब्ध नहीं हैं। Seen status के लिए server permission आवश्यक है।
